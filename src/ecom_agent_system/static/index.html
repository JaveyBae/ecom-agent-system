        • 同一个问题同时用 BM25（jieba 分词、按字面匹配）和向量（Qwen3-Embedding）检索，再用加权 RRF 融合成“融合结果”。

        • 拖动权重滑块只重新融合，不重新检索，可以直接看到名次怎么变。
        • 正文里黄色是问题里的词，绿色是同义词扩展出来的法规用语。
